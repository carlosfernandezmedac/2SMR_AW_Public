## ¿Qué vamos a ver este curso?

La asignatura sigue un hilo conductor: pasar de **escribir una página web a mano** a **instalar y administrar las aplicaciones web** que usan empresas y centros educativos.

```
Bloque 1  ──►  Construir una página   → HTML (contenido), CSS (aspecto), JS/PHP (comportamiento)
Bloque 2  ──►  Web 2.0 y servidores   → la web colaborativa y el servidor donde viven las páginas
Bloque 3  ──►  Gestores de contenido  → WordPress: una web completa sin escribir todo el código
Bloque 4  ──►  Aprendizaje a distancia→ Moodle: montar un aula virtual como la que usáis
Bloque 5  ──►  Otras aplicaciones web → nube de archivos, ofimática, correo y calendario en el navegador
```

Cada bloque se apoya en el anterior: primero entiendes **de qué está hecha** una página web, después **dónde se aloja**, y por último **instalas y administras** aplicaciones completas que, por dentro, usan todo lo anterior.

## Herramientas

- **Visual Studio Code** + extensión **Live Server** — para escribir HTML/CSS y ver los cambios al guardar
- **Navegador (Chrome/Firefox)** + herramientas de desarrollador (**F12**) — para inspeccionar cualquier página
- **XAMPP** — servidor web Apache + PHP + MySQL en tu propio equipo
- **WordPress** y **Moodle** — las aplicaciones web que instalaremos y administraremos
