# Bloque 1 — Construir una página web

En este bloque aprendes de qué está hecha cualquier página web. Al terminarlo sabrás escribir una página con su contenido, darle un aspecto cuidado y entender cómo se le añade comportamiento.

| Tema | Título | Qué harás |
|------|--------|-----------|
| [Tema 1](tema01/README.md) | Introducción a las aplicaciones web | Entender cliente-servidor, web estática y dinámica, HTTP |
| [Tema 2](tema02/apuntes.md) | El lenguaje de marcas (HTML) | Escribir páginas con textos, listas, imágenes, enlaces, tablas y formularios |
| [Tema 3](tema03/apuntes.md) | Hojas de estilo (CSS) | Dar color, tipografía, fondos y cajas a tus páginas |
| Tema 4 | Lenguajes de script cliente y servidor | Primeros pasos con JavaScript y PHP |

---

## Hilo conductor del bloque

Una página web se construye por capas, igual que una casa:

```
            ┌──────────────────────────────┐
  Tema 4 ►  │  JavaScript / PHP            │  ← comportamiento (la instalación eléctrica)
            ├──────────────────────────────┤
  Tema 3 ►  │  CSS                         │  ← aspecto (pintura y decoración)
            ├──────────────────────────────┤
  Tema 2 ►  │  HTML                        │  ← estructura y contenido (paredes y habitaciones)
            └──────────────────────────────┘
  Tema 1 ►  El terreno: navegador, servidor, Internet y el protocolo HTTP
```

Durante el bloque trabajamos siempre sobre **la misma mini-web** (página de inicio, contacto y formulario) que vamos ampliando tema a tema.
