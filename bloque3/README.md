# Bloque 3 — Web 2.0 y gestores de contenido

En este bloque ves cómo se publica hoy en la web sin escribir todo el código. Primero conocerás la **web 2.0** (blogs, wikis, podcasts, RSS) y después los **gestores de contenido (CMS)**. Al terminarlo sabrás instalar **WordPress** en tu XAMPP y montar un blog con usuarios.

| Tema | Título | Qué harás |
|------|--------|-----------|
| [Tema 5](tema05/apuntes.md) | Aplicaciones web 2.0 | Conocer blogs, wikis, podcasts, RSS y redes sociales |
| [Tema 7](tema07/apuntes.md) | Los gestores de contenido (CMS) | Saber qué es un CMS, sus partes, tipos y licencias |
| [Tema 8](tema08/apuntes.md) | Instalación y configuración de un CMS | Instalar WordPress, crear contenido y usuarios |
